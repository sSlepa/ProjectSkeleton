# AI Usage

## Tools used

- **Claude Opus 4.7** (Anthropic) — used through Claude Code (VS Code extension)
  for chat-based code suggestions and small targeted refactors while I was writing
  the game on top of `dotNETUVT/ProjectSkeleton`.

No image / sound / font assets were generated by AI; the project reuses
`grass_001..004.png` and `player.png` shipped with the skeleton.

## How AI was used

Mostly chat-based code suggestions and rubber-ducking: I described what I wanted
(grid Bomberman with hard/soft walls, cross-pattern bombs, random-walking enemies,
power-ups, win/lose, persisted high score), wrote the code, and used Claude to
sanity-check my collision math, suggest the structure of the explosion chain
loop, and tighten a couple of switch-expression refactors.

For one file I let the model produce a first draft that I then read line-by-line
and accepted. That file is listed below as fully AI-generated and is
inline-marked accordingly.

## Fully AI-generated files

The following file has `// AI-generated` ... `// end AI-generated` markers
around the class body. Everything inside those markers came from the model; I
reviewed it before keeping it.

- `Engine.cs` — the main game loop, bomb chain detonation, explosion-effect
  application, win/lose plumbing and HUD wiring.

## My own code (with occasional AI tweaks)

These files I wrote myself; the model occasionally suggested a tighter form for
a switch or a small condition, but the structure and logic are mine:

- `Models/GameMap.cs` — grid, generation pattern, world/grid conversions.
- `Models/Enemy.cs` — random-walker AI: turns at tile centres, picks a random
  valid direction (avoiding immediate reversals) when blocked.
- `Models/PlayerObject.cs` — grid-aware player with AABB collision against walls
  and bombs and the "bomb you just placed is passable until you walk off"
  bookkeeping.
- `Models/Bomb.cs`, `Models/Explosion.cs` — bomb / explosion entities.
- `Models/PowerUp.cs`, `Models/Direction.cs`, `Models/TileType.cs`,
  `Models/IDamageable.cs`.
- `Game/HighScoreStore.cs` — async JSON load/save (atomic via tmp + Move).
- `Game/PixelFont.cs` — 3x5 bitmap font + glyph table.
- `Game/GameState.cs`, `Exceptions/LevelLoadException.cs`.
- `GameRenderer.cs`, `Input.cs`, `Program.cs`, `GameWindow.cs` — additive changes
  on top of the skeleton's existing files.

Skeleton files left untouched are not listed here.
